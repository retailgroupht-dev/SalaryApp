За номером ТТН або замовлення

Статус, сума, дата продажу, канал і товар підтягуються з Нової Пошти та кабінетів Prom / Rozetka / Епіцентр (Налаштування → Кабінети), за тими ж правилами, що й скрипт у таблицях. Якщо замовлення є лише в Новій Пошті без ключа відправника, суми не буде — вкажіть вручну.

Відправлення

Усе, що створено в кабінетах Prom / Rozetka / Епіцентр працівника за місяць, звірене з Новою Поштою. Нічого вручну додавати не треба: натисніть «Зібрати», перегляньте й додайте в замовлення — вони потраплять у розрахунок зарплати. Повторне додавання лише оновлює статуси. Замовлення спільних кабінетів (ключ без працівника) показуються лише коли вибрано одного працівника.

Автоматичне оновлення

Застосунок сам збирає відправлення з кабінетів за поточний і попередній місяць, додає їх у замовлення і перевіряє все зі статусом «Перевіряється». Запускається через 20 секунд після старту й далі за розкладом.

Кабінети: Нова Пошта і маркетплейси

Ключі API кабінетів, у яких застосунок шукає замовлення за номером: звідти беруться статус, сума, дата продажу й канал (назва кабінету). Нова Пошта без ключа віддає лише статус і дати. Найпростіше — вставити код Apps Script з таблиці (Розширення → Apps Script): ключі з нього підхопляться самі. Кабінет можна прив’язати до працівника: тоді його замовлення шукаються лише там (+ у спільних). Один і той самий ключ у двох працівників стає спільним.

Локальний API

HTTP-доступ до даних для інших програм і скриптів на цьому комп'ютері: замовлення, працівники, розрахунок, файли експорту, резервна копія. Адреса 127.0.0.1 — лише з цього комп'ютера; 0.0.0.0 — також з локальної мережі (тоді обов'язково задайте ключ).

Резервна копія — один файл із замовленнями, працівниками, ставками і ключами кабінетів. Так можна перенести все на інший комп’ютер: там відновити з цього файлу. Відновлення замінює поточні дані.
