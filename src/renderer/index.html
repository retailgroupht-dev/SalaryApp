Статус і дата беруться з Нової Пошти автоматично. Суму післяплати Нова Пошта віддає лише з ключем відправника (Налаштування → Нова Пошта); без ключа або для передплачених замовлень суму вкажіть вручну.

Працівники

Порожня ставка = загальна ставка з налаштувань. Видалення працівника видаляє і його замовлення.

Налаштування

Нова Пошта

Ключ API відправника (кабінет Нової Пошти → Налаштування → Безпека → Ключі API). Без ключа трекінг теж працює: статус і дати є, але суми післяплати й опису відправлення Нова Пошта не віддає.

Локальний API

HTTP-доступ до даних для інших програм і скриптів на цьому комп'ютері: замовлення, працівники, розрахунок, файли експорту, резервна копія. Адреса 127.0.0.1 — лише з цього комп'ютера; 0.0.0.0 — також з локальної мережі (тоді обов'язково задайте ключ).
